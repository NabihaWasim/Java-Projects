# Bank Account Management System

## About the Project

The Bank Account Management System is a beginner-friendly Java console-based project designed to practise Object-Oriented Programming (OOP) concepts.

The goal of this project is to understand how classes and objects work together to represent real-world entities and manage their data and behaviour.

This project will be developed step by step as I learn and apply Java OOP concepts.

## Project Goals

- Understand classes and objects.
- Learn how constructors initialise objects.
- Practise fields, methods, and access modifiers.
- Understand encapsulation and data protection.
- Apply inheritance, polymorphism, and abstraction as I learn them.
- Improve Java programming and problem-solving skills.

## Planned Features

- Create a bank account.
- Store the account holder's name and account balance.
- Check the current balance.
- Deposit money into the account.
- Withdraw money from the account.
- Prevent invalid deposit and withdrawal amounts.
- Prevent withdrawals exceeding the available balance.
- Display account details.

## Technologies Used

- Java
- Visual Studio Code
- Git and GitHub

## OOP Concepts to Practise

| Concept | Planned Application |
|---|---|
| Class and Object | Represent a bank account |
| Constructor | Initialise account details |
| Encapsulation | Protect account data |
| Methods | Implement deposit and withdrawal operations |
| Inheritance | Explore specialised account types |
| Polymorphism | Explore different account behaviours |
| Abstraction | Hide unnecessary implementation details |
