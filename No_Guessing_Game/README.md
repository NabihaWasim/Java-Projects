# Number Guessing Game

## About
A beginner-friendly Java console game where the user guesses a randomly generated number between 1 and 100.

## Features
- Random number generation
- User input using Scanner
- Hints for higher and lower guesses
- Counts the total number of attempts

## Concepts Used
- Java basics
- Scanner
- Math.random()
- do-while loop
- if-else statements

## How to Run
1. Make sure Java JDK is installed.
2. Open the project folder in the terminal.
3. Compile the program:

   `javac Guess_Number.java`

4. Run the program:

   `java Guess_Number`

## Learning Outcome
Practised loops, conditional statements, user input, and basic problem-solving in Java.
